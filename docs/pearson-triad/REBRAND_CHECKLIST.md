# Rebrand Checklist

To rename Pearson Triad later:
1. Change values in `frontend/src/lib/pearson-triad-brand.ts`.
2. Replace logo/media references when added.
3. Update legal/customer-facing documents only after the new legal/DBA identity is approved.
4. Do not rename neutral domain entities, pipeline stages, pricing logic, fulfillment logic, QC records, finance records, or Zola event contracts solely for a brand change.

Goal: public rebrand should be a configuration/content operation, not a business-system rewrite.
